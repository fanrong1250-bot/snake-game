# 🐍 贪吃蛇小游戏（Node.js 终端版）

一个用纯 Node.js 编写的命令行贪吃蛇游戏，无需任何第三方依赖。

## 运行

需要安装 [Node.js](https://nodejs.org/)（任意较新版本即可），然后在本目录执行：

```bash
node snake.js
```

或者：

```bash
npm start
```

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制蛇移动方向 |
| `P` | 暂停 / 继续 |
| `R` | 游戏结束后重新开始 |
| `Q` 或 `Ctrl+C` | 退出游戏 |

## 玩法

- 控制蛇去吃 🍎，每吃到一个得 **10 分**，蛇身会变长，速度略微加快。
- 撞到墙壁、自己的身体或 🧱 障碍物则游戏结束。
- 不能直接 180° 反向移动。

## 网页版特性

- **难度选择**：简单 / 普通 / 困难 / 地狱，决定初始速度、加速幅度和障碍物数量；每个难度单独记录最高分。
- **音效**：吃食物、转向、死亡都有提示音（Web Audio 合成，无外部文件），右上角 🔊 或按 `M` 可静音。
- **障碍物** 🧱：从「普通」难度起出现，撞到即结束（出生通道有安全区，不会一开局就死）。
- **触屏支持**：移动端显示方向键，也支持在画面上滑动控制。

## 配置

可在 `snake.js` 顶部修改游戏参数：

- `WIDTH` / `HEIGHT`：游戏区域大小
- `TICK_MS`：蛇移动间隔（毫秒），数值越小速度越快

> 提示：请在真实的终端中运行（需要 TTY 支持键盘输入），部分 IDE 的内置输出窗口可能无法接收按键。
